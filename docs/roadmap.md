# Roadmap

- Capture: scripted interaction states (click/open before measuring), capture diff between two markets or releases, selector re-check in CI.
- Platform wrappers: activation, polling and SPA re-activation snippets for the major testing tools.
- Brief adapters shipped as packages (read ideas from an experimentation tool and write `brief.md`).
- Multi-variant experiments sharing one brief.
- Visual regression helper (screenshot diff control vs variation, desktop and mobile).
- Typed config and JSDoc types published with the packages.

Contributions welcome: see CONTRIBUTING.md.
