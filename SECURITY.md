# Security

CRO Studio produces code that runs inside other people's websites, so security reports matter.

Report vulnerabilities privately through GitHub Security Advisories on this repository (not public issues). Include the version, a minimal reproduction and the impact. Expect an acknowledgement within a few days.

In scope: `@cro-studio/core` and the CLI (path handling, config parsing, generated payloads, template injection). Out of scope: bugs in your own variations or in a testing platform.
